# NV Portfolio

Personal portfolio for **Mahadev (NV)** — a product designer & full-stack engineer.

Inspired by the clarity and motion of premium studio sites, built as a unique personal brand experience.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Deploy

Connected to GitHub (`mahadevrollwin`) and deployed on Vercel.
